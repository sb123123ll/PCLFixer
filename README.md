# PCL2 原版下载一键修复补丁工具 (PCLFixer)

一款专为 Plain Craft Launcher 2 (PCL2) 设计的原版 Minecraft 下载与版本列表恢复工具。

---

##  项目背景与用途

近期部分 PCL2 在线更新或拉取云端策略后，进入【下载】页面时会弹出如下提示：
> “为遵守相关法律法规，PCL 暂时不再提供 MC 下载功能，非常抱歉 qwq……”

导致启动器内的版本列表被遮挡无法显示，且无法直接下载原版客户端、快照版与配套组件。

本工具通过对本地启动器环境与运行库进行全自动分析和字节码修补：
1. **自动识别定位**：智能扫描并定位用户电脑中的 PCL2 启动器位置。
2. **恢复原版下载**：恢复下载模块的 `DlClientListLoader` 版本列表加载器与下载流程。
3. **屏蔽停服弹窗**：清理本地云端停服公告缓存，屏蔽后续的公告弹窗与强制诱导。
4. **安全防冲突**：修复前自动结束正在运行的冲突进程，并自动创建 `.bak` 备份，安全无痛。

##  使用方法

1. 下载并运行 `PCL2原版下载一键修复工具.exe`；
2. 工具会自动识别你电脑中的 PCL2 路径（若未识别，点击【浏览...】手动选择你的 `Plain Craft Launcher 2.exe`）；
3. 点击【立即开始修复】；
4. 提示修复成功后，重新启动 PCL2 并进入【下载】页面，即可恢复正常的原版版本列表与下载功能。
